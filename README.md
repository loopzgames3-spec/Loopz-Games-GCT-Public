# Loopz-Games-GCT-Public
Game Creation Tool — Public Development Release

Loopz Games G.C.T officially releases to the public on **April 8, 2026**. The program is still under active development but we are committed to giving continuous support, fixing bugs as they appear and adding new features regularly.

## 📋 Update Log 1.0 — Compatibility & Major Changes
**📅 March 29, 2026**

This update was focused on building a solid and compatible foundation for the engine. A lot of internal work went into this one to make sure the tool runs well for as many people as possible.

**What changed:**
- Improved the `.loopz` file format for better stability and compatibility
- Added support for older Windows versions (Windows 7 and forward)
- Early compatibility work for MacOS and Linux
- Improved the overall GUI layout and user experience
- Rewrote and improved the built-in tutorial
- Improved the internal logic of the engine
- Added multi-language translations
- Added customizable UI themes — Dark, Dark Blue, Sakura and more
- Engine optimizations to reduce unnecessary resource usage on your device

**Known issues:**
- The `.exe` exporter does not work exactly as intended yet — it currently works partially through an alternative method. This is actively being worked on.

Plans for the next update include a major GUI upgrade and further internal optimizations.

That's all for today.

## 🔧 Update Log 1.0.1 — Bug Fixes & New Features
**📅 April 8, 2026**

This update focuses on fixing a critical crash bug in the Sprite Editor and introducing the new built-in auto-update system so future updates reach you automatically without needing to check manually.

**🐛 Bugs Fixed:**
- Fixed a crash when opening the Sprite & Animation Editor
  (the `_on_sheet_hover` method was missing, causing the editor to fail immediately on launch)

**✨ New Features:**
- **Built-in Auto-updater** — a new option in Help → Check for Updates connects to our servers, compares your version and if a newer one is available it downloads and installs it automatically, then restarts the program
- **Real download progress bar** — the update window now shows actual MB downloaded vs total instead of a generic spinning bar
- **Icon fix** — `app_icon.ico` now correctly appears in both the window title bar and the Windows taskbar when running as an `.exe`

That's all for today.
